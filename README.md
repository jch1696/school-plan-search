# 학교 계획서 검색기

정보공개포털(open.go.kr)에 올라오는 교육청·학교 원문정보(계획서, 보고서 등)를
키워드로 모아 두고 내 PC에서 빠르게 검색하는 도구입니다.

## 파일

| 파일 | 역할 |
|---|---|
| `opengo.py` | 정보공개포털 검색 요청을 보내고 결과를 SQLite(`opengo.db`)에 저장하는 핵심 모듈 |
| `collect.py` | `keywords.txt`의 검색어를 한꺼번에 수집 (주기 실행용) |
| `keywords.txt` | 관심 검색어 목록 (한 줄에 하나) |
| `wonmun.py` | 원문 파일 다운로드(본문 PDF, 첨부 HWP) + 텍스트 추출 + 본문 전문검색 |
| `server.py` | 로컬 서버(FastAPI). 화면과 Python 기능을 이어 준다 |
| `static/index.html` | 화면 (HTML/JS). 검색 조건 · 결과 목록 · 문서 상세 3단 구성 |
| `files/` | 내려받은 원문 파일 (문서번호별 폴더) |
| `export_web.py` | 웹용 목록(`docs/data.json`) 내보내기·합치기 |
| `docs/` | GitHub Pages로 공개되는 웹 페이지. 제목 검색 + 포털 원문 링크 + 포털에서 가져오기 |

## 웹에서 쓰기 (다른 PC, 다른 선생님)

https://jch1696.github.io/school-plan-search/ — 설치 없이 브라우저만 있으면 됩니다.
제목 검색, 정보공개포털 원문 보기(거기서 파일 받기), 포털에서 새로 가져오기가 됩니다.
파일 일괄 다운로드, 본문 검색, OCR은 PC 프로그램에서만 됩니다.

- **누구나**: 검색과 "정보공개포털에서 보기".
- **가져오기(실행 키 필요)**: 검색어를 넣고 왼쪽 아래 "가져오기"를 누르면 GitHub Actions가 포털을 검색해
  목록에 추가합니다(1~2분). 실행 키는 관리자(저장소 주인)가 만들어 믿을 만한 분에게만 알려 줍니다.
  만드는 법: GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** →
  Repository access: `school-plan-search`만, Permissions → Actions: **Read and write**. 이 저장소의 워크플로 실행 외엔
  아무 권한도 없는 키입니다. 키는 각자 브라우저에만 저장됩니다.
- **파일 받기(실행 키 필요)**: 문서의 "파일 받기"를 누르면 GitHub Actions가 포털에서 본문·붙임을 전부 받아
  zip으로 올려 주고, 페이지에 "zip 받기" 링크가 생깁니다(1~2분). 포털 화면은 2026-09부터 교육기관 붙임파일
  버튼을 숨겼지만 이 방법으로는 받아집니다. zip은 **3일 뒤 자동 삭제**됩니다(매일 새벽 정리).
- **PC와 합치기**: PC에서 **`웹 목록 올리기.bat`** 을 더블클릭하면 웹에서 모은 문서를 PC DB에 넣고,
  PC에서 수집한 문서를 웹 목록에 올립니다.

GitHub에는 코드와 목록(`docs/data.json`)만 올라가고, 받은 파일·DB·`settings.json`은 올라가지 않습니다(`.gitignore`).

## 사용법

가장 쉬운 방법: 폴더의 **`학교계획서검색기 실행.bat`** 을 더블클릭하면 검은 창이 뜨고 1~2초 뒤
브라우저에 화면(http://localhost:8765)이 열립니다. 검은 창을 닫으면 프로그램이 꺼집니다.
**`검색어 일괄수집.bat`** 을 더블클릭하면 `keywords.txt`의 검색어를 한꺼번에 수집합니다.

명령어로 쓰려면:

```bash
# 1) 검색어 목록 수집 (최근 30일)
python collect.py

# 2) 검색 화면 열기
python server.py
```

검색어 하나만 바로 수집하려면:

```bash
python opengo.py "독서교육 계획" 90
```

화면 왼쪽에서도 검색어를 넣고 수집할 수 있습니다. 같은 문서는 두 번 저장되지 않으므로
자주 실행해도 괜찮습니다.

## 알아둘 점

- 정보공개포털에는 공식 Open API가 없어서, 브라우저가 보내는 검색 요청을 그대로 재현합니다.
  사이트가 개편되면 `opengo.py`를 손봐야 할 수 있습니다.
- 사이트는 접속 시 브라우저 지문을 등록해야 검색을 허용합니다(안 하면 code 491).
  `opengo._session()`이 이 절차를 대신합니다.
- 검색 기간은 사이트 정책상 최대 1년입니다.
- 저장 폴더: 화면 오른쪽 위 "변경"을 누르면 폴더 선택 창이 뜹니다. 그 뒤로 받는 파일은 모두
  거기에 저장됩니다(설정은 `settings.json`에 기억). 기본값은 `files/`.
- 원문 받기: 목록에서 문서를 클릭하면 오른쪽에 파일 목록이 나오고, 체크한 파일만
  "선택한 파일 받기"로 받습니다. 파일명은 `[학교] 제목 - 원래파일명` 형태(끌 수 있음).
  받은 파일은 본문 텍스트가 추출되어 "본문으로 찾기" 탭에서 검색됩니다.
- 본문 PDF(결재문서본문.pdf)는 거의 항상 받을 수 있고, 첨부 HWP는 학교가 비공개로 올린 경우
  "비공개 파일" 오류로 실패합니다. 이건 사이트에서도 똑같이 못 받는 파일입니다.
- "(05) 처리량이 많아 지연" 오류는 사이트 쪽 혼잡이라 잠시 뒤 다시 받으면 됩니다(자동으로 몇 번 재시도).
- HWP 본문은 한글 파일 구조를 직접 읽어 추출하므로 표 안 글자 일부가 빠질 수 있습니다.
